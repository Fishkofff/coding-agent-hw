# Отчёт по спринту

1. Прочитай `tasks.json` и `sprint.json` (название спринта и дата отчёта `today`) одним ответом,
   двумя вызовами `read_file`. Повторно эти файлы не читай: их содержимое уже в контексте.
2. Раздели задачи на две группы:
   - полные: поле `status` равно `open`, `in_progress` или `closed`;
   - неполные: поля `status` нет или значение другое. Неполные задачи не считаются ни открытыми,
     ни просроченными, их статус не угадывается.
3. Посчитай полные задачи по статусам. Проверь: open + in_progress + closed + неполные = всего задач.
4. Просроченная задача: полная, статус не `closed`, есть `due`, и `due` раньше `today`
   (даты ГГГГ-ММ-ДД сравниваются как строки).
5. Запиши `report.md` строго в формате:

```
# Отчёт по спринту <name>
Дата отчёта: <today>
Всего задач: <N>

## Статусы
- open: <число>
- in_progress: <число>
- closed: <число>

## Просрочено
- <ID> — <title> (срок <due>, статус <status>)

## Неполные данные
- <ID> — <чего не хватает>
```

   Пустой раздел — строка `- нет`.
6. Перечитай `report.md` через `read_file` и сверь числа с шагом 3.
7. В ответе кратко перескажи итоги, ничего не добавляя сверх данных.
