# Сообщение коммита

1. Посмотри, какие файлы и как изменены.
2. Выбери тип: `feat` — новая возможность, `fix` — исправление, `docs` — документация,
   `refactor` — изменение без новой функциональности, `test` — тесты.
3. Первая строка: `<тип>(<область>): <что сделано>` в повелительном наклонении, до 72 символов.
4. Пустая строка, затем тело: зачем сделано изменение и что важно знать ревьюеру.
5. Не придумывай изменения, которых нет. Верни сообщение пользователю, коммит не выполняй.
