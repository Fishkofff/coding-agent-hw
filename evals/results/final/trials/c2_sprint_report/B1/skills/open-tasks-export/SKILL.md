# Выгрузка открытых задач

Соглашение команды: открытой считается любая задача, у которой статус не `closed`,
то есть статусы `open` и `in_progress`.

1. Получи задачи из источника. Если источник — трекер, вызови MCP-инструмент `list_tasks`
   без фильтра по статусу: фильтр вернёт только один статус, и задачи `in_progress` потеряются.
2. Если источник вернул ошибку или недоступен, НЕ создавай файл и не придумывай данные.
   Сообщи пользователю, что источник недоступен, и приведи текст ошибки.
3. Отбери задачи со статусом `open` и `in_progress`. Задачи без статуса не включай
   и перечисли их в ответе отдельно.
4. Запиши в файл JSON-массив строк: только ID, без объектов и пояснений,
   по возрастанию номера, например `["T1", "T3"]`.
5. Прочитай записанный файл через `read_file` и сверь ID с отобранными.
6. В ответе назови файл и число задач.
